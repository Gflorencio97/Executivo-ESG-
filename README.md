# Evoluttion - Executivo & ESG 2026

Cockpit executivo e dinâmico desenvolvido para acompanhamento de KPIs industriais, metas corporativas de redução de custos (Savings) e diretrizes ESG (Ambiental, Social e Governança).

O sistema substitui planilhas Excel fragmentadas por uma interface moderna, reativa e interativa.

---

## 🚀 Tecnologias Utilizadas
* **React 18**
* **Vite**
* **Tailwind CSS**
* **Recharts** (Gráficos interativos)
* **Lucide Icons**
* **XLSX** (Leitura e processamento de planilhas)

---

## 📊 Módulos Principais
1. **Visão Executiva (Diretoria)**: Termômetro da meta de R$ 1,53M de saving, cartões com farol inteligente, gráficos de evolução mensal e distribuição de economias por departamento.
2. **Cockpit ESG**: Métricas detalhadas de Energia (R$/peça e kWh), Água, Resíduos industriais, Absenteísmo, Turnover, NBR 14283 e os 8 pilares estratégicos de Governança.
3. **Projetos ESG**: Gestão do portfólio de iniciativas sustentáveis vinculadas às ODS da ONU, com cálculo de investimento e saving anual.
4. **Visão Departamental**: Drill-down por setor com menu lateral fixo (Fábrica, Compras, Qualidade, Manutenção, Processos, Almoxarifado, Comercial, Engenharia).
5. **Plano de Ação 5W2H (Kanban)**: Gestão ágil de iniciativas com cálculo automático de economias capturadas vs pipeline.
6. **Central de Atualização**: Lançamento mensal simplificado via formulário web ou importação por arraste da planilha `.xlsx`.

## 🛠️ Como Executar Localmente

### Pré-requisitos:
* Node.js 18+ instalado

### Instalação:
```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```

Acesse no navegador: `http://localhost:5173`
